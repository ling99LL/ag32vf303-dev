# FOC2205 领域术语

FOC2205 面向基于 2205 无刷电机的力反馈旋钮。本上下文独立于工作区内的其他旋钮工程。

## Language

**力反馈旋钮（SmartKnob）**：
通过电机主动施加旋转方向的力，让使用者在转动时感受到反馈的旋钮。
_Avoid_: 普通旋转编码器（只表达旋转输入，不能完整表达本项目的主动施力目标）

**运动动作**：
一次有起止边界的转动或施力过程。动作完成与达到原定目标位置是不同的概念。

**保持态（HOLD）**：
以指定保持位置为基准，抑制旋钮偏离的工作状态。进入保持态不等同于抵达本次运动的原定目标。

当前固件保留状态值 2，但不进入主动 HOLD；正常结束关闭功率级并上报 DONE，随后转为无输出待命。主动保持属于后续能力。

**力矩释放**：
停止主动施力、允许旋钮自由转动的状态，不表示旋钮已被机械锁止。

**无输出待命**：
模块可通信但不驱动电机、等待新运动命令的状态。故障恢复成功后也进入此状态。

**动作残差**：
一次运动收尾时，原定目标位置与实际位置之间的差。

位置动作在到位带宽外受阻时报告故障，不用 DONE 代替到位；开环 DONE 只代表矢量推进时间结束，实际机械圈数需独立核验。

**力反馈旋钮模块**：
可嵌入其他设备、由宿主设备提供具体应用语义的旋钮硬件与固件单元；首版交付边界不包含独立外壳或完整终端应用。
_Avoid_: 独立旋钮成品

**宿主设备**：
使用力反馈旋钮模块、向模块发送模式/参数并接收角度、按压和状态的上层设备或电脑上位机。

**基础运动验收**：
在定义具体手感模式前，对旋钮的转动、定位、停止、反馈释放和异常恢复进行的底层能力验收。

**安全释放**：
模块异常保护时停止主动施力并关闭电机功率输出的状态；通信仍可用于查询与请求恢复。

**恢复命令**：
宿主在安全释放后明确提出、仅在故障原因消除后使模块回到无输出待命的请求；不续跑故障前的运动。
