# ADR-0001：首版交付为可嵌入力反馈旋钮模块

## Status

Accepted

## Context

FOC2205 的工程定位是基于 2205 无刷电机的 SmartKnob，但当前仓库主要实现电机驱动、角度反馈、运动控制和调试工具，尚未定义独立终端产品的外壳、显示、应用场景和完整交互。继续把这些内容混入首版会使机械、主机协议和手感验收互相牵连。

## Decision

首版交付定义为**可嵌入其他设备的力反馈旋钮模块**。模块负责旋钮位置/按压感知、电机反馈和必要的宿主通信；具体应用语义由宿主设备决定。独立外壳、显示和终端应用不属于首版交付边界。

## Consequences

- 必须先定义模块与宿主之间的电气接口、通信协议、供电边界和故障安全行为。
- 手感模式需要有可独立验收的接口和指标，不依赖某个尚未确定的终端应用。
- 后续做独立成品时，可以在模块协议之上增加外壳、显示和应用层，而不改变核心电机控制边界。
