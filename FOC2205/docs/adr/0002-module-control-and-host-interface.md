# ADR-0002：模块本地控制，UART 115200 连接宿主

## Status

Accepted

## Context

首版交付是经过完整测试、包含控制 PCB、2205 电机、MT6701 磁编码器/磁铁、宿主连接器和安装基准的完整机电模块。模块需要先把转圈等基础运动调稳，再承载尚未确定的具体手感模式。

## Decision

模块在本地运行位置环、手感逻辑和安全保护；宿主通过 UART TTL 115200 配置模式/参数，并接收角度、按压和状态数据。首版同时提供电脑控制的上位机和正式数据包协议。心跳超时、驱动故障或编码器 CRC 异常时，模块立即释放力矩并关闭功率级，同时保留串口通信，由宿主通过明确的串口命令请求恢复。模块确认故障原因已消除后，仅进入无输出待命，等待新的运动命令，不自动续跑故障前的动作。

## Consequences

- UART 数据包、心跳、状态、故障和恢复命令必须成为正式协议，而不能继续依赖单字符调试命令。
- 基础运动必须有独立验收指标；第一种面向用户的手感模式暂不决定。
- 恢复必须是显式动作，不能因为串口重新收到任意数据就自动重新通电；故障仍存在时不得恢复。
- 正常停止应释放电机，允许自由转动；主动位置保持另行验收。
