# 闭环平滑扫描记录 2026-10-17（深夜 · 无人值守）

承接 [10-17 通电记录](powered-debug-2026-10-17.md)。目标：在电流环可用的前提下，用串口脚本跑"不同速度 × 不同力度"的闭环（位置伺服 `r`/`R`）单圈矩阵，回答动作是否平滑：按时到位、速度稳定、无失步/反向、无跳闸。本记录同时更正 10-17 文档中若干判读。

条件与证据边界：`fw=20261017.1`，COM26 115200 8N1；全部动作为 1 圈（`r` 正向 / `R` 反向）；"力度" = `vq_max` 调制上限（mod LSB，1 圈参考 4096）；"平滑度" 用编码器角速度统计（cv = 巡航速度变异系数、jitter 峰值、100 ms 步进毛刺）与完成情况衡量。无示波器/相电流波形，不作物理力矩/电流幅值结论。

## 0. 结论速览

1. **决定性发现：混合换向（hybrid，开机默认 ON）会让控制 ISR 从 20 kHz 掉到 ~12 kHz**，动作真实时长变为名义值的 ~1.67 倍（实际转速只剩命令值的 ~60%），且毛刺计数升高。关掉（`y`）后 20 kHz 恢复、动作全速。10-17 文档 A/B 段的"变慢"判读据此更正（见 §2）。
2. **运动环 kp 2→8（`k` 两次）是后半程最大单项收益**：0.05–0.25 圈/秒巡航 cv 由 31/21/35% 降到 10.2/7.4/3.6%，残差收紧到 ±32–51 raw；适用范围下限 0.05 圈/秒——0.02 档 kp=8 双向真实跳闸，该档保持 kp=2（§6.5–§6.9）。
3. 推荐平滑配置（**均为运行时设定，重启不保留**）：`y`（hybrid 关）、`j`→`kd=60/1000`、`q`→`ang_filt=1/256`、`k`×2→kp=8（仅 ≥0.05 圈/秒档），其余默认（ki=1.5、follow=500、vel_win=256、speed=0.05、vq_max=2048）。电流环 `l` 按需，默认关；力度上限与 0.50 档禁用说明见 §7。
4. 候选配置（kp=2）基础矩阵、确认与重复性不变（§5、§6、§6.1）；扩展批 ki 档重扫（保持电流环 ki=100）、0.02 环 ON/OFF、0.5 圈/秒初测（§6.2–§6.4）。
5. 五连圈验收：kp=2 版 40 步（§6.6）0.05–0.25 全 DONE、0.50/1013 5/10 起步真实跳闸；kp=8 版 50 步（§6.7）0.05/0.10 各 10/10、0.25 9/10（1 次结束前跳闸）、0.50 15/20（起步 MT6701 场状态中止 3 + 起步真实跳闸 2）。kp=8 力度切片 8/8（§6.8）、24 圈 soak 零漂移零跳闸（§6.10）。
6. 过流判别遥测实弹验证（本记录累计 270 个取证动作，含前段 134）：真实 n=3 跳闸 15 次、MT6701 场状态中止 5 次。除已知有害档（运动 kd=200、follow=200，§6.5）与边缘档（0.02、0.50）外，常规组合仅 0.25 档 1 次单发跳闸。电流环 K/I 保持默认 8/100。
7. 未决：hybrid 的固件侧每拍开销优化（§8）；0.25 档间歇单发跳闸与 0.50 起步两种失败模式的机理（力度/增益都不能消除，§6.7）；`ref_div` 无串口入口；慢速/30 rpm 的"体感"需实机握持确认。

## 1. 方法

脚本（`experiments/tests/current_loop/`，均为串口主机脚本，逐条串行使用 COM26）：

- `smoothness_sweep.py`：主扫描器。块 `matrix`（0.05/0.10/0.25 × 2048/1536/~1024）、`slow`（0.02 全力度）、`ref`（环 OFF 对照）、`repeat`、`gains`（K/I 档）、`tune`（单变量：kp/kd/vel_win/filt/follow）、`cand`（候选配置抽检）、`candmat`（候选配置全矩阵）、`candrep`（重复性）、`kiscan`/`slow2`/`fast`（扩展批）。`--hybrid 0/1` 决定起始 hybrid；每步 JSON 落盘、故障自动 `z` 恢复、结束收尾（环 OFF、0.05、2048）。
- `hyb_rate_test.py`：只翻 `y`，主机计时 + 250 ms ISR 计数对照。
- `session_close.py`：候选配置确认（环 ON 2 圈 + OFF 2 圈）与收尾。
- `smooth_analyze.py`：日志离析（cv、步进毛刺按角度聚类、stall 计数）辅助脚本。

时间读法：状态帧 `up=` 来自 mcycle，是真实毫秒；`MOVE DONE ... in N ms` 来自 ISR 计数时基（`s_hz`），实际 ISR 频率低于名义值时真实时长被拉长。两者对不上即 ISR 降频的直接证据。

## 2. 决定性发现：hybrid 使 ISR 降频

`hyb_rate_test`（0.05 圈/秒、vq_max 2048、1 圈；日志 `015133-hyb-rate-test.txt`）：

| 用例 | 主机实测 | 设备报 | 移动期间 ISR 计数 | 折算速率 |
|---|---|---|---|---|
| hyb0 + 环 ON | 20.25 s | 20052 ms | ~4990/250ms | ~20.1 kHz ✓ |
| hyb0 + 环 OFF | 20.31 s | 20052 ms | ~4990/250ms | ~20.1 kHz ✓ |
| hyb1 + 环 OFF | 33.83 s | 20052 ms | ~3080–3390/250ms | ~12.1 kHz ✗ |

- 空闲（不动）时两组都是 ~5000/250ms（20 kHz）；只有"hybrid ON 且正在动作"才掉速 → 开销在 `hybrid_step` 的每拍路径（软浮点运算；按 ISR 计数反推约 82 µs/拍 vs 50 µs 预算，未直接测执行时间）。
- 10-17 文档 A/B 段的直接更正（`003807-currentloop-accept.txt` 的 `up=` 实时钟）：

| 段 | 配置 | `up=` 真实时长 | 设备报 | 真实转速 |
|---|---|---|---|---|
| A（电压模式） | hyb=1, cl=0 | 424638→458117 = **33.5 s** | 20052 ms | ≈1.79 rpm（文档误作 2.98 rpm） |
| B（电流环） | hyb=1, cl=1 | 460172→494805 = **34.6 s** | 20052 ms | ≈1.73 rpm |

A/B 等速变慢，**与电流环无关**，是 hyb=1 的 ISR 降频；10-17 文档 §二"B 段变慢 = 环的问题"与 §三"配置敏感性"判读作废。hyb=0 的 24 步扫描（`015334-smooth-hyb0.*`）中所有动作时长回到名义值（0.05→20.05 s、0.10→10.05 s、0.25→4.1–4.8 s），环 ON/OFF 均如此。
- 操作规则：凡 `hybrid=1` 的动作，设备报 ms 均被拉长 ~1.67×、换算转速一律失真；取证前先 `d` 确认 `hybrid=` 字段。

## 3. 过流遥测的实弹验证

- 真实 n=3 跳闸快照（kp=16 用例 `T-CKP16-R`，`020207-smooth-tune1.txt:3289`）：0.05/2048、hyb0、环 ON；`MOVE ABORT: current ADC threshold C n=3` at t=13098 ms；`OC snap: kind=trip run=3 mask=4`，C 相末 3 拍 -217/-228/-217 LSB（≈290–305 mA），前 5 拍 |I|≤2。fault 锁存，`z` 恢复成功。
- 第二次真实 n=3 跳闸快照（`022849-smooth-ext1.txt`，0.25/2048 反向 `FA-F2048-R`）：起步 ~3 ms 即 `MOVE ABORT: current ADC threshold C n=3`；`OC snap: kind=trip run=3 mask=4`，C 相 -269/-305/-423 LSB（≈-360…-567 mA），此前 5 拍仅 -1/0；位置 ang≈14085（与 kp16 现场 14287 同区，未验证是否磁平衡簇）。fault 锁存，`z` 恢复成功。
- 截至扩展批 134 个取证动作的超阈连续长度分布：maxrun=1 有 85 次、maxrun=2 有 47 次、maxrun≥3 仅 2 次（即上下两处现场）。正常配置下超阈全部 ≤2 连拍 → 归为 glitch，不跳闸；18 步矩阵的 18 个快照全部 `kind=glitch`。
- 判读：连续 3 拍判据把"孤立采样毛刺"（每圈 5–27 次；0.02 圈/秒的环诱发尖峰见 §6.3）与连续超阈簇（n=3）分开。两次跳闸均为 C 相；每簇的物理来源（真实电流还是 ≥3 拍的传感器/采样瞬态）无波形证据不能定论，判别、锁存与 `z` 恢复路径均按设计工作。

## 7. 推荐配置与开机序列

开机默认（掉电不保留本记录任何设置）→ 复现平滑动作的最小序列：

```
y   # hybrid 关（关键；开机默认是开）
j   # kd 20/1000 -> 60/1000（档位表 0/10/20/60/200）
q   # ang_filt 1/64 -> 1/256（档位表 1/1/16/1/64/1/256/1/1024）
k   # 运动 kp 2 -> 4，再按一次 -> 8（仅 ≥0.05 圈/秒档；0.02 档不要按）
l   # 需要电流环时再开（默认关；仅待机且输出关闭时可切）
```

边界说明：`hybrid`/`kd`/`ang_filt`/`kp` 等均为运行时变量，**重启后必须重新设置**。hybrid 当前是固件已知缺陷区（每拍开销超预算）；修好之前"开机默认 ON 的 hybrid + 闭环动作"不适合直接使用。是否把 `MOTION_HYBRID_DEFAULT` 改为 0（会失去滑差自校正，属产品行为决策）或先优化其每拍开销，留待下一轮决定。0.50 档起步中止后固件自动安全停机（输出关闭），`z` 清故障后可直接重发动作重试。

力度上限按速度选择（kp=8 实测，§6.7/§6.8）：

| 速度档 | 力度上限 | 依据 |
|---|---|---|
| 0.02 圈/秒 | 保持 kp=2；kp=8 会双向跳闸 | §6.9 |
| 0.05 圈/秒 | 1024–2048 均可 | §6.7/§6.8 |
| 0.10 圈/秒 | 1536–2048 均可 | §6.7/§6.8 |
| 0.25 圈/秒 | 1024–1536（2048 双向前 2 步通过，样本小） | §6.7/§6.8 |
| 0.50 圈/秒 | **不建议常规使用**：起步 ~25–40% 安全中止（两种模式均与力度/增益无关）；跑起来后最平（cv 1–3%） | §6.4 更正注/§6.7 |

## 8. 遗留

1. hybrid 每拍开销优化 / 默认值决策（20 kHz→12 kHz，固件问题未修）。
2. 跟随手感基线（需实机握持）；`ref_div` 无串口入口（固件项）。ki 重扫已完成（§6.2，保持电流环 ki=100）。
3. 0.02 圈/秒超阈密度：定位为电流环诱发（§6.3），且与运动 kp 强相关（kp=8 会跳闸，§6.9）；低速环是否需要限幅/更积极滤波待评估。
4. 0.25 档间歇单发真实跳闸（§6.7 R3，结束前 t≈4 s）：kp=8 下 14 步中 1 次；条件未定，保留 ≤1536 力度观察。
5. 0.50 档（30 rpm）起步两种失败模式（MT6701 场状态中止 §6.4/§6.7、起步真实过流）：kp 2/8、力度 768/1013 均无法消除；传感器/机构域取证（细粒度 MT6701 场状态记录、示波器相电流）仍缺。
6. 相电流/功率波形测量（示波器）依旧缺（10-17 文档遗留项不变）。
7. 开环六组合的重复性未做（本记录闭环重复见 §6.6/§6.7，24 圈 soak 见 §6.10）。
8. 运动环 kp 默认值（`g_motion_cfg.kp=2`，motion.c:17）是否改为 8——≥0.05 档全面优于 kp=2，但 0.02 档会跳闸；默认值决策需要"分档默认"或固件侧低速限幅。
