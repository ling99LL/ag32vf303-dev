# FOC2205 m0–m4 力反馈手感验收记录（2026-10-17）

## 结论

`fw=20261017.23` 已在实板完成烧录和校准；m0–m4 与开环矩阵在 `.19` 上完成，
`.20–.23` 仅调整闭环 SPIN 的电流环策略、位置安全/平滑档和上位机遥测刷新，未改手感/开环算法。

- m0 自由、m1 阻尼、m2 惯性、m3 连续角挡位通过自动矩阵；m4 软边界保持原行为。
- m3 当前在 0°/22°/40°/60° 四个挡位点均无跳闸，实测峰值电流约
  43/245/683/36 LSB；挡位算法本身不再被过流保护误杀。
- 1 rps 开环 SPIN 的 20% 力度在 V1–V4、正反方向共 8/8 通过，失联释放 PASS。
- 开环 40% 在 1 rps 和 0.1 rps 都出现真实过流（峰值约 1.93–1.95 k LSB），
  因此开环力度上限已统一降为 20%；低速也不再允许 40%。
- m4 当前仍是**安全软边界**：边界外保持约 57 Q12 的持续反力，但静摩擦下
  不会主动把转子硬拉到 45°。m4 硬边界尚未完成。
- 闭环 SPIN 未作为本轮通过项：20% 电压模式仍有明显速度振荡，80% 会触发
  `current ADC threshold n=3`。电流环本身能跟踪 `iref`，但位置环仍需整定；
  这不影响 m0–m4 与开环 1 rps 的验证结果。
- GUI 的 ±1 圈按钮原先直接发 `r/R`，沿用 `vq_max=2048`、0.25 圈/秒，57 ms 即
  `current ADC threshold A n=3`。`.21` 起按钮改发 `rot ±360`，固件在 `rot` 内
  限速 0.05 圈/秒、`vq≤512`；实板 +1 圈 0.995 圈、-1 圈 0.996 圈，均约
  20.118 s 完成，无过流。
- `.22` 在 `rot` 内固定位置平滑预设 `kp=4`、`kd=0.2`、`ki=0`、
  `vel_win=256`、`ang_filt=1/64`。+1 圈实测完成 1001/1000 圈、残差 -14 raw，
  jitter 均值/峰值由约 5996/11254 降到 **898/5236 raw/s**（理想速度 819 raw/s）。
- `.23` 的 `$T` 增加原始 MT6701 角字段，GUI 主表盘按遥测率刷新；原先只由 0.5 s
  一次的 `?` 状态帧刷新，主角度实际约 2 Hz。CSV 改为 0.5 s 周期 flush，避免
  100 Hz 遥测时 GUI 线程逐帧落盘造成卡顿/看似掉帧。
- 本板磁铁/旋钮装配方向与 MT6701 原始计数相反；上位机统一按反向显示主角度、
  指针和累计圈数，固件内部换向方向不受影响。

自动证据和人工体感必须分开看：本文的 PASS 是遥测、状态机和保护链证据，
不等同于已经由人手确认阻尼、惯性、挡位咔哒和边界手感。

## 根因与修复

### 1. PWM 电流采样边沿错误

中心对齐 PWM 使用 mode 1：谷点时 INHx 为高、低边 MOSFET 关断，低边 shunt/CSA
不成立；原来的 ISR 在谷点采样，某些换向角下会读到单相 `-2032 LSB` 左右的
假电流（B/C 接近 0，三相电流和不守恒）。这会让 m3 的合法挡位力矩被误判为
过流。现已改为在峰值/低边导通窗口触发 ADC，见 `src/pwm3ph.c` 和
`src/foc.c` 的注释。

### 2. 过流阈值过低

原 `CURRENT_TRIP_LSB=200`（约 269 mA）会误杀正常的 5% 校准电流和挡位电流。
现在默认值为 `1800 LSB`（约 2.4 A，1 LSB≈1.34 mA），仍低于电机 2.5 A
额定值；判断规则保留“同一相连续 3 拍超阈才跳闸”，孤立尖峰只计入 glitch。

### 3. 开环启动冲击

开环电压模式没有电流环，直接把 20% 力矩加到静止转子上会在约 70 ms 产生
1.5–1.7 k LSB 的真实启动电流。`motion.c` 已加入软启动：先以 10% 调制起步，
再在 300 ms 内升到目标力度。开环力度上限同时改为 20%，避免选择必跳闸的 40% 档。

## 实现

- `src/haptic.c/h`：m0–m4 的 Q12 力矩算法，使用 MT6701 14 位连续角。
- m0：零力矩，功率级保持使能；`s` 完全释放。
- m1：`tq = -df * vel`。
- m2：`tq = +fi * vel`，辅助力矩上限为手感力度上限的 8%。
- m3：连续角挡位，`dw/ds/es/sp/sb/pn/px` 控制宽度、挡力、限位、吸附、偏置和序号；
  强 P 负责跨挡，静止后在挡心 2° 内缓慢回中，避免持续站立力矩。
- m4：边界外使用速度目标式 PD（最大回边速度 0.35 rad/s）；边界内只有 `kf` 轻阻尼。
- HAPTIC ISR 对编码器单拍跳变做 30 rad/s 上限拒绝，避免瞬态假角度直接进入手感环。
- m 模式有 1 秒宿主看门狗；合法命令或 `?` 刷新心跳，超时立即释放功率级。
- 参数和中心不写 Flash；首次进入以当前角度设中心，`cd` 可重设。

## 默认参数

| 参数 | 默认 | 说明 |
|---|---:|---|
| `df` | 0.10 | m1 阻尼 |
| `fi` | 0.05 | m2 惯性，最大输出 8% |
| `dw` | 30° | m3 挡宽 |
| `ds` / `es` | 2.5 / 4.0 | m3 挡力 / 限位力 |
| `sp` / `sb` | 0.6 / 0 | m3 吸附点 / 偏置 |
| `pn` / `px` | 0 / -1 | m3 不限挡位范围 |
| `br` | 45° | m4 边界 |
| `kp` / `kd` / `kf` | 5.0 / 0.3 / 0.02 | m4 速度目标增益 / 阻尼 / 区内阻尼 |
| `vl` | 20% | 手感模式力度上限 |

## 协议

- `#FOC,proto=3,...`：`mode=3` 表示手感模式，`hm/hact/hpos/hsub/htgt/hto` 提供模式、
  挡位和保护状态。
- `$T,3,hm,ang,vel,tq,tgt,pos,sub,st,out,hz,raw`：紧凑遥测，`raw` 为 MT6701 原始角；
  `tel <hz>` 支持 0/10/20/50/100 Hz，主表盘按该频率刷新。
- `rot <deg>`：相对定位，供自动探针摆位；动作完成会释放输出。
- 旧单字符命令保持兼容，裸 `m` 仍是三相手动模式。
- 开环 SPIN 的 `W1..W8` 统一钳到 20%；闭环上限仍为 80%。

运行环境：COM26、115200、`foc2205_bringup`、`fw=20261017.19`（`.20/.21` 仅改

### m4 边界深度

46/48/50/52/54° 五个进入深度全部稳定，尾段峰峰值 0°，力矩约 57 Q12，无故障。
这仍是软边界，不是机械硬止挡。

### 1 rps 开环与保护

`accept_spin.py --mode open --forces 20 --speeds V1,V2,V3,V4`：

```text

V2 forward / reverse   PASS
```

没有触发连续 3 拍；W4 在开环下被钳为 20%。10% 开环此前连续 3/3 通过，
峰值约 991 LSB。
