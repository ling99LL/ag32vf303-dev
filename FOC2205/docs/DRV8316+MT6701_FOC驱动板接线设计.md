## 0. 三个关键设计约束（全部经源码/手册核实，行号可查）

### 0.1 硬 SPI 是固定 mode 0，两颗从机都要 mode 1 —— 必须过 CPLD 包装核
- AG32 硬 SPI（SPI0/SPI1）**无 CPOL/CPHA 配置位**（`framework-agrv_sdk/src/spi.h` L19-39、`AgRV2K.svd` SPI_CTRL 字段穷举）；AGM 官方 `examples/spi/full_duplex_spi` 例程的存在目的就是"给硬 SPI 补 CPOL/CPHA"，其 core 反推出硬 SPI 原生 = mode 0（空闲低、上升沿采样）。
- MT6701 SSI（手册 p26）："在 CLK 的上升沿发送数据，**建议在 CLK 的下降沿采集数据**" = mode 1。
  DRV8316C（手册 p5/p54）："Data is captured on the **falling edge** of SCLK, propagated on the **rising edge**"，且 "SCLK should be low when nSCS transitions" = mode 1。
- **结论**：SPI0/SPI1 的 SCK/MOSI/CSN 进 CPLD 的 `spi_mode_wrap`（mode-1 重定沿），MISO 由包装核在外部 SCK 下降沿采样，经 APB 寄存器交给固件。硬 SPI 只当帧发生器。
- 帧格式核实：MT6701 = **恰好 24 clk**（14bit 角度 + 4bit Mg + 6bit CRC，X⁶+X+1，CRC 覆盖前 18 位）；DRV8316 = **恰好 16 clk**（多/少都报 SPI_SCLK_FLT 故障，p55），MSB 先，B8=偶校验位。

### 0.2 GPIO 撞位 —— CSN/nSLEEP 绝不能用 GPIO0_0/GPIO0_1
`etc/gen_vlog` FUNC_PINS（L450-451）证实 `SPI0_SI_IO0` 与 `GPIO0_0` 是**同一物理 GPIO 位**（SPI0_SO_IO1↔GPIO0_1 同理；SPI1_SI_IO0↔GPIO0_4、SPI1_SO_IO1↔GPIO0_5）。
**规则**：SPI0 占用 GPIO0_0/0_1 期间，GPIO0_0/0_1 不可另作他用；本设计 CSN/nSLEEP 改用空闲位 **GPIO2_0 / GPIO2_1**。

### 0.3 ADC 不是 MCU 外设 —— 必须走 CPLD logic（analog_ip）
SVD/AltaRiscv.h 无 ADC（0 命中）。ADC 是 logic 侧 `alta_adc` 硬宏，3 个独立实例（各有 insel/START/DMA），AHB 窗口 0x60000000/1000/2000，17:1 mux，12bit。
**构建要点**：`logic/analog_ip.v` 参数 **ENABLE_ADC0/1/2 = 1**（默认只开 ADC0！）、**ENABLE_DAC0/1 = 0**（DAC0/1 与 PIN_11/12 同 pad，启用会顶牛 SOB/SOC）、**ENABLE_CMP0 = 0**（CMP_PA4/5 同样占 PIN_11/12）。
无 TRGO→ADC 硬件触发 → 同步采样 = GPTIMER0 更新中断内背靠背写 3 个 START（错开几十 ns，准同时）。

## 2. MT6701QT-STD 接线表（QFN3x3-16）

| MT6701 脚 | 信号 | 接 MCU / 电平 | 方式 | 上下拉 |
|---|---|---|---|---|
| 7 | CLK | PIN_13（包装核出） | **直连** | 无 |
| 6 | DO | PIN_28（进包装核） | **直连** | 无（推挽输出，VOH≥2.8V@3.3V > VIH 1.5V）|
| 8 | CSN | PIN_14（GPIO2_0） | **直连** | 无（片内 200k 上拉保高）|
| 14 | MODE | **接 VDD(3.3V)** | 直连 | 无（片内 200k 上拉，悬空亦可；**勿接地** = ABZ 组）|
| 5 | PUSH | 悬空 | — | 无（按压经 SSI 帧 Mg[2] 读出，不占脚）|
| 13 | VDD | **3.3V 主轨（独立 LDO 输出，P2-1 整改：不再借用 DRV8316 AVDD）** | 直连 | 100nF + TVS(6V) 按 MT6701 图-23；**板上不设 5V 烧写跳线**（P2-2：EEPROM 编程走 I²C 且需 4.5-5.5V，只能离线编程座完成，见下方说明）|
| 6/7/8 复用 | SDA/SCL | 不接 I2C | — | I2C/SSI 共脚，按主机协议自识别 |
| 1,2,3,4,9,10,11,12,15,16 | NC/OUT/U/V/W/GND | NC 悬空；9=GND；16=GND | — | 无 |

**SSI 帧（24 clk，MSB 先）**：`[23:10]=D[13:0] 角度`，`[9:6]=Mg[3:0]`（Mg[2]=按压、Mg[1:0]=磁场强度 0=正常/1=过强/2=太弱、Mg[3]=超速），`[5:0]=CRC6`（X⁶+X+1，覆盖 D+Mg 共 18 位，查表法见固件 mt6701.c，与 SmartKnob 参考实现一致）。
**时序**：TCLK ≥ 64ns（≤15.6MHz），本设计 12.5MHz=80ns；CSN↓→首 CLK↑ ≥100ns（包装核保证 ≥120ns）；末 CLK↓→CSN↑ ≥0.5·TCLK（包装核尾沿+固件双重保证）；DO 更新于 CLK 上升沿（TDV≤15ns），包装核在下降沿采样。
角度换算：θ = D/16384 × 360°（安装方向相反时取 1−θ）。

**EEPROM 说明（P2-2 整改）**：MT6701 出厂默认即可跑 SSI 模式（MODE=VDD 决定接口，与 EEPROM 无关），本设计**不需要烧写 EEPROM**。如将来要改 ABZ 分辨率/UVW 对极数：EEPROM 编程走 **I²C** 接口且必须 4.5V<VDD<5.5V（手册 §8.2，密钥 0xB3→0x09、命令 0x05→0x0A、等待 ≥600ms），只能在**离线编程座**上完成；严禁在板上把 VDD 切到 5V——MT6701 推挽 DO 会输出 ~5V 直接灌进 AG32 的 PIN_28（AGRV2K IO 为 3.3V LVCMOS/LVTTL，**无 5V 耐压**，AGRV2K datasheet 电气章节全文无 5V tolerant 字样）。

| 40/39/38 | SOA/SOB/SOC | PIN_10/11/12 | 直连 + RC | **330Ω 串联 + 22pF 到 GND，放在 ADC 端**（手册 §9.2.1.1.6 推荐）|

**3x PWM 模式依据（手册 p22 Table 8-4）**：`INLx=1, INHx=0 → L`；`INLx=1, INHx=1 → H`；`INLx=0 → Hi-Z`。死区由 DRV8316 内部 VGS 检测自动生成（tdead 500ns typ @200V/µs slew），与模式无关 → MCU 不配 DTG、不用互补输出。
**INL_EN 时序（P0-3 整改核心）**：冷启动时 DRV 寄存器复位为 6x 模式（CTRL2=0x60），INLx=0（10k 下拉）+ INHx=0（片内下拉）→ Table 8-3 的 Hi-Z 态，安全滑行；固件写 CTRL2 切 3x 时 INLx 仍为 0（满足 Table 8-2 Note）→ 写完拉高 INL_EN → 3x 正常驱动。**MCU 热复位**（DRV 不断电，寄存器保持 3x）：INLx=0 → 3x 模式 Hi-Z 滑行，同样安全。
**MCU 复位期安全性**：INHx 被 70-130k 内部下拉钳低（最坏 1µA×70k=70mV ≪ VIL 0.6V）→ 冷启动 6x 模式（INL=0,INH=0）= Hi-Z；热复位 3x 模式（INL=0）= Hi-Z。两态均无直通、无力矩。若需要复位期低边刹车而非滑行，可在 main 循环里主动置 brake（本设计默认滑行，手感旋钮静止时无影响）。

## 4. SPI / SSI 通信规格

| 项 | SPI0 → DRV8316C | SPI1 → MT6701（SSI）|
|---|---|---|
| 模式 | mode 1（包装核输出：SCLK 空闲低、下降沿采样）| 同左 |
| 时钟 | 6.25MHz（APB 100MHz / DIV16，上限 10MHz）| 12.5MHz（DIV8，上限 15.6MHz）|
| 帧 | **恰好 16 clk**，MSB 先 | **恰好 24 clk**，MSB 先 |
| 帧内容 | SDI: B15=W(0写/1读), B14:9=A[5:0], B8=偶校验, B7:0=D[7:0]；SDO: [15:8]=STAT, [7:0]=回读数据 | [23:10]=角度, [9:6]=Mg, [5:0]=CRC6 |
| CSN | nSCS 硬件整形（下降提前≥120ns、上升滞后≥120ns）| GPIO2_0 固件定时（≥150ns 建立/保持）|
| 帧时间 | 2.56µs | 1.92µs |
| 读出通路 | 包装核 SPIW RXDATA 寄存器（0x60007000）| 同左 |

**SPI 寄存器地址（DRV8316）**：IC_STAT=0x0, STAT1=0x1, STAT2=0x2, CTRL1=0x3, CTRL2=0x4, CTRL3=0x5, CTRL4=0x6, CTRL5=0x7, CTRL6=0x8, CTRL10=0xC。
**清故障两条路**：CTRL2 bit0 CLR_FLT（W1C）；或 nSLEEP 20-40µs 低脉冲（还清 OTP_ERR 之外的锁存）。

## 5. 电源树与固定电平（v4 重写：独立 LDO 架构）

```
VM(4.5-24V) ── DRV8316 功率级 ── 电机三相
   │
   ├─ 独立 3.3V LDO（输入接 VM，输出 ≥150mA）
   │    ├─ AG32 VDD33(6/16/32)
   │    ├─ MT6701 VDD(13) + 100nF + TVS(6V)        ← P2-1：不再借用 AVDD
   │    ├─ nFAULT 5.1k 上拉
   │    └─ nSLEEP 10k 上拉                          ← P1-2：上电即唤醒 DRV
   ├─ AVDD(内部 LDO, 30mA, CTRL6 BUCK_PS_DIS=1 → 从 VM 取电)
   │    └─ VREF + 0.1µF（DRV 内部电路自理；INLx/MT6701 均已移出）
   └─ CP: CPH/CPL 电荷泵电容按手册
```
- **为什么必须独立 LDO（P1-2，实测规格书 p53）**：nSLEEP=0 的睡眠模式关断 buck、AVDD、SPI 总线；nSLEEP 片内下拉意味着上电即睡。若 MCU 供电取自 DRV 的 buck，上电瞬间 buck 已关、MCU 无电、永远拉不高 nSLEEP → 死锁。**只有从 VM 直接取电的 LDO 能打破这个环**（buck→LDO 级联也不行，睡眠时 buck 本身就停）。
- **DRV8316 buck 网络不贴**（SW_BK 电感、FB_BK/C_BK 电容全部 DNP），固件写 **CTRL6=0x11**（BUCK_PS_DIS=1 + BUCK_DIS=1）。
- **VM 范围放宽为 4.5-24V**（DRV UVLO 4.5V；原 VM≥7V 约束来自 buck，已随 buck 弃用解除）。LDO 选型：VM≤15V 可用 AMS1117-3.3；需 24V 耐压用 78M33（35V）或同级宽压 LDO。
- AG32 固定外围：NRST(4) 10k 上拉+100nF；BOOT0(30) 10k 下拉（flash 启动）；PIN_2/3 = 8MHz 晶振 + 负载电容（按晶振规格 8-22pF）；GND(17)、散热 pad→AGND。
- 逻辑电平兼容性（全直连的依据）：AG32 VIH 1.5V < MT6701 VOH 2.8V / DRV8316 SDO VOH 2.2V / GPIO 3.3V；DRV8316 输入 VIH 1.5V（nSLEEP 1.6V）< 3.3V ✓；MT6701/DRV8316/AG32 全部工作在 3.3V 域（**注意：AGRV2K IO 是 3.3V LVCMOS/LVTTL，无 5V 耐压——v3 文档此处"5.5V 容限"有误，已修正**）。

## 6. DRV8316 初始化序列（固件 drv8316.c，v4 加入 INL_EN 时序）

```
0. 硬件保证：nSLEEP 已被 10k 上拉=1；INL_EN(GPIO2_2)=0（app_io_init 置低+10k 下拉）
1. 延时 ≥ 50ms（TPwrUp 上电时序 + tREADY 1ms SPI 就绪）
2. 三相 PWM 输出全低（MOE=0 且 OSSI 下拉低，INHx=0）
3. CTRL1 = 0x03          # REG_LOCK 解锁
4. CTRL6 = 0x11          # BUCK_PS_DIS=1（AVDD 从 VM 取电）+ BUCK_DIS=1（buck 不贴）
5. CTRL2 = 0x7C          # 保留位 01 + SDO_MODE=1(推挽) + SLEW=11b(200V/µs) + PWM_MODE=10b(3x)
                         # ← 此刻 INHx=0、INLx=0，满足 Table 8-2 Note
6. CTRL5 = 0x02          # CSA_GAIN=0.6V/A（code 2；旋钮小电流电机可改 0x03=1.2V/A）
7. CTRL10 = 0x15         # DLYCMP_EN=1 + DLY_TARGET=0x5(1.2µs @200V/µs，手册 Table 8-6)
8. CTRL2 bit0 CLR_FLT = 1（重写当前 CTRL2 值+W1C，INLx 仍为 0）
9. INL_EN = 1（GPIO2_2 拉高）→ 3x 模式 INLx=1 = 正常驱动
10. 回读 CTRL2/CTRL6 自检（期望 0x7C/0x11），通过后才开 PWM（MOE）
```
注意：上电默认 PWM_MODE=00b 是 **6x 模式**（INL=0/INH=0 = Hi-Z，安全）；**改 PWM_MODE 前 INHx/INLx 全低由步骤 2 + 步骤 0 共同满足**（v3 版"INLx 恒高"违反此条，已整改）。热复位时 DRV 寄存器保持 3x，INLx=0 → Hi-Z 滑行，同样安全。

## 7. 电流采样与同步（固件 current.c）

- SOA/SOB/SOC → ADC_IN3/4/5（PIN_10/11/12），增益 0.6V/A，VREF=AVDD → 双极性 ±(AVDD/2)/0.6A。
- 每路 RC：330Ω + 22pF（fc≈22MHz，采样保持驱动友好；带宽约束靠固件数字滤波）。
- 同步：GPTIMER0 更新中断（中心对齐模式上溢+下溢各触发一次 = 40kHz；**ISR 入口按 CNT>ARR/2 门控，只在下溢=波谷执行**——低边采样电阻只有波谷时刻才有效。不用 RCR 分频：其相位取决于使能顺序，落错边会丢掉全部波谷）。谷底 ISR 内背靠背写 ADC0/1/2 的 START（准同时，偏移 <100ns）→ 轮询 EOC 读 DATA（13 sclk ≈1.04µs 转换，三路并行）。
- 上电零点校准：电机不励磁时采 256 次取均值存 offset。
- 电压模式阶段电流不进控制环：ISR 内每 16 拍采一次作遥测（约 1.25kHz，示波器/日志核对谷底采样正确性）；进入电流环后恢复全速采样。
- 无 TRGO 硬件触发（SVD 无 ADC、定时器事件不出 fabric）—— 已核实的硬约束；ISR 抖动 ±200ns 在 20-40kHz 环内可接受。

## 8. 布局要点（手感/信号完整性）

1. **SOx RC 靠近 ADC 端**（PIN_10/11/12 侧），SOA/B/C 走线短、等长、远离 SW 节点。
2. **AGND/PGND 分割**，单点汇于 DRV8316 散热 pad 下方；MT6701 在电机轴线上但**远离电感/buck 电容**（磁场干净度直接决定角度噪声 = 手感）。
3. VM 大电流环（VM 电容→半桥→GND）最短；CP 电荷泵电容贴 25/26 脚。
4. nFAULT 5.1k 上拉电阻放 MCU 端；走线避开 SW 节点。
5. MT6701 的 VDD 去耦 100nF 贴片；MODE 直接短接到 VDD（不要引线悬空）。
6. 晶振走线包地；BOOT0/NRST 电阻放 MCU 近端。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| SSI 首位时序假设（MSB 于首 CLK↑ 出）与器件实际行为不符 | 每帧 CRC6 校验兜底；若 CRC 恒错且错位固定 1bit → 调包装核采样沿或固件移位（降级方案 B） |
| nFAULT 在上电/nSLEEP 脉冲期间被手册行为拉低（假故障） | 固件在 nSLEEP 操作与上电 50ms 内屏蔽 BRK；BKF 滤波 FDIV4 以上 |
| DRV8316 帧长错误（≠16clk）报 SPI_SCLK_FLT | 固件用 SPI_Send 单相发帧（v3 误用 SPI_SendAndReceive = 32/48clk，已整改）；STAT2 定期巡检 |
| CTRL 偶校验位算错导致 SPI_PARITY | 固件 parity 覆盖 B15:9+B7:0；首测读 STAT2 确认 |
| INL_EN 与 PWM 时序错配（INL=0 时开 PWM = 全 Hi-Z 无力矩） | 固件顺序固定：drv8316_init（INL=0）→ 自检 → drv_inl_high() → 对齐/开环；上板 gate ② 核对 |
| AG32 引脚 5V 倒灌（EEPROM 烧写/异常源） | 板上无 5V 源（跳线已删）；AGRV2K IO 无 5V 耐压（AGRV2K datasheet），任何 5V 信号禁止直入 |
| DAC/CMP 宏占用 PIN_11/12 | analog_ip.v 强制 ENABLE_DAC0/1=0、ENABLE_CMP0=0 |
| PIN_26/28（JTDI/JNTRST）输出不可靠 | 只放输入（BRK/MISO），输出全在纯 IO 脚（PIN_15 亦为纯 IO） |

```
analog_ip.v      官方模板改参：ENABLE_ADC0/1/2=1, DAC0/1=0, CMP0=0；
                 APB 译码扩 1 槽（0x60007000）挂 spi_mode_wrap

reg_ctrl.v       官方配套（REG0 通用寄存器，保留作调试）

                 ├ SCK/MOSI 同管线延迟 12 拍（120ns@100MHz）→ 满足全部建立/保持
                 ├ CSN 整形：下降立即、末沿排空后延 12 拍再升（≥0.5·TCLK）
                 ├ MISO 在外部 SCK 下降沿捕获 → 32bit 移位寄存器
                 └ APB 寄存器：SPIW0_RXDATA / SPIW1_RXDATA / SPIW_STATUS
my_board.asf/.sdc 模拟宏定位（ADC×3），按 QFN32 实测微调
```

**MCU 侧读取流程**：`SPI_Send(...)`（硬 SPI 单相发帧 = 纯时钟发生器，阻塞等 DONE）→ 短延时 → 读 `0x60007000` RXDATA → 解析/CRC。（禁用 `SPI_SendAndReceive`：它是 TX/RX 两相顺序执行，时钟数翻倍，见整改记录 P0-1。）
