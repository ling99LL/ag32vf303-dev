## 1. 概述与核心设计准则

本设计面向 2205 无刷电机的力反馈控制（SmartKnob），在紧凑型 QFN32 封装下实现完备的三相 FOC 矢量控制。

### 1.1 三大零占用红线（硬性隔离）
1. **调试接口零干扰**：PIN_24 (JTMS), PIN_25 (JTCK), PIN_26 (JTDI), PIN_27 (JTDO) 保持 100% 独立。PIN_28 (JNTRST) 承接 INL_EN 业务复用——DAPLink 仅走 2 线 Compact-JTAG（TCK/TMS），从不驱动 nTRST；且 JTAG TAP 复位本可用 TMS 保持高电平 5 拍实现，nTRST 属可选信号，烧录与在线调试完全不受影响。
2. **外部高频晶振零占用**：PIN_2 (OSC_IN), PIN_3 (OSC_OUT) 100% 独立保留给 8MHz 石英晶体。
3. **硬件启动引脚零占用**：PIN_15 (BOOT1) 与 PIN_30 (BOOT0) 均通过独立 10kΩ 电阻下拉接地，硬件级锁定 {BOOT1, BOOT0} = 00b（从内部 Flash 启动），彻底消除运行期 IO 翻转引起的复位模式误采样。

## 2. MCU（AG32VF303KCU6）物理引脚分配总表

QFN32 封装共 32 个物理管脚，分配精算如下：
- **供电与地（4 个）**：PIN_6 (VDDA33), PIN_16 (VDD33), PIN_32 (VDD33), PIN_17 (GND)
- **系统与启动（3 个）**：PIN_4 (NRST), PIN_15 (BOOT1), PIN_30 (BOOT0)
- **外部晶振（2 个）**：PIN_2 (OSC_IN), PIN_3 (OSC_OUT)
- **JTAG 调试（4 个）**：PIN_24 ~ PIN_27（PIN_28/JNTRST 已作 INL_EN 业务复用，2 线 DAPLink 调试不受影响）
- **可用纯净 IO**：**18 个**
- **业务需求 IO**：**18 个**（完美收敛，无冲突）

## 3. DRV8316CRRGFR 驱动接口电路设计

DRV8316C 内部集成三相半桥功率 MOSFET（最大支持 40V 母线、峰值 8A 电流）、硬件电流检测放大器（CSA）以及 3.3V/5V LDO/Buck。

### 3.1 3x PWM 模式控制与使能时序（P0-3 级安全防直通机制）
- **控制逻辑**：
  - 上桥臂：由 AG32 高级定时器 PIN_7 (INHA), PIN_8 (INHB), PIN_9 (INHC) 提供 20kHz 单边 PWM 信号（3x 模式每相仅一根 PWM 线，无互补/死区概念）。
  - 下桥臂：INLA/B/C（引脚 28, 30, 32）在 PCB 上短接为单一网络 DRV_INL_ALL，接入 AG32 的 **PIN_28（GPIO2_2，JNTRST 焊盘）**，并外加 10kΩ 电阻下拉到 GND。
- **动态互锁时序设计**：
  1. **上电复位阶段**：由于 PIN_28 外部 10kΩ 下拉（JNTRST 复位期的片内上拉被强下拉支配），网络钉在低电平，INLA/B/C 保持 0V。此时即使 DRV8316 处于上电默认的 6x 模式，其下桥 MOS 也被强行切断，避免直通冲击。
  2. **配置生效阶段**：MCU 启动后，先保持 PIN_28 为低电平，通过 SPI 向 DRV8316 写入 PWM_MODE = 3x 并校验成功。
  3. **运行使能阶段**：MCU 将 PIN_28 置高（3.3V 推挽），满足 DRV8316 规格书 3x PWM 模式下下桥常高的要求，功率桥正式进入 PWM 调制运转。

### 3.2 故障极速硬件刹车保护（BRK）
- **网络连接**：DRV8316 的 
FAULT（开漏报警脚）外接 5.1kΩ 上拉电阻到 3.3V（规格书要求上电时该脚 ≥2.2V，否则芯片进测试模式），直连 AG32 的 **PIN_22（GPTIMER0_BRK）**。
- **响应速度**：当 DRV8316 检测到过流（OCP）、过温（TSD）或欠压（UVLO）时，
FAULT 瞬间拉低。AG32 定时器内部硬件刹车逻辑在 **1 个系统时钟（5ns）** 内强制关闭三相 PWM 输出，无需等待软件中断介入，从物理上杜绝炸机风险。

### 3.3 三相电流采样输入接口（SOA / SOB / SOC）
- **引脚对应**：
  - DRV8316 SOA $ightarrow$ AG32 PIN_10 (ADC_IN3)
  - DRV8316 SOB $ightarrow$ AG32 PIN_11 (ADC_IN4)
  - DRV8316 SOC $ightarrow$ AG32 PIN_12 (ADC_IN5)
- **运放参数与滤波**：
  - DRV8316 内部 CSA 配置为内部增益 0.15V/A 或 0.3V/A，输出零偏为 {	ext{REF}}/2 pprox 1.65	ext{V}$。
  - PCB 走线时，SOA/B/C 走线必须做等长、包地屏蔽，且在靠近 AG32 引脚处先串 330Ω 再对 GND 并 22pF NPO 陶瓷电容（规格书 Table 6-1 明确 SOx 支持串阻+对地电容的低通接法）。

## 4. MT6701QT-STD 磁编码器接口电路设计

MT6701 是 14 位磁性角度传感器，本方案采用 24-bit 硬件 SSI 差分串行协议实现超高速角度读取。

### 4.1 协议时序与模式转换桥
- **供电与模式配置**：
  - VDD 接主板系统 +3.3V，配 1uF + 100nF 去耦滤波。
  - MODE 引脚直接接 +3.3V（配置为 SSI 数字输出模式）。
- **信号互联**：
  - CLK $ightarrow$ 接 AG32 PIN_13 (spi1_sck_o)（12.5MHz 高速时钟，Mode 1 相位）
  - CSN $ightarrow$ 接 AG32 PIN_14 (spi1_csn_go)（帧同步片选）
  - DO  $ightarrow$ 接 AG32 PIN_23 (spi1_miso_i)（串行数据输出）
- **CPLD 硬件桥**：
  - AG32 片上硬核 SPI1 固定为 Mode 0，通过片上 CPLD 内建的 spi_mode_wrap.v 自动在物理层转换为 Mode 1 时钟相位，MCU 无需消耗 CPU 算力进行软件位模拟，单帧 24-bit 数据读取时间压缩至 **1.92μs**。
- **数据帧格式**：
  - 14 位角度数据 + 4 位状态（磁场状态/按压状态）+ 6 位硬件 CRC 校验，固件层具备每帧 CRC 校验与重试熔断机制。

## 5. 电源拓扑与地平面隔离规划

驱动板采用 2 层或 4 层板设计，电源拓扑建议如下：

`
[外部输入 DC 8V~24V] 
     │
     ├──────────────────────────► DRV8316 VM (功率母线供电，并联 22uF/35V + 100uF 固态电容)
     │
     └─► [高性能 LDO (如 SGM2036-3.3 或 ME6211)] 
              │
              ├─► +3.3V (数字主轨) ──► AG32 VDD33 (PIN_16, PIN_32)
              │                     ──► MT6701 VDD
              │                     ──► JTAG/UART 上拉电阻
              │
              └─► [磁珠 (FB) + 10uF + 100nF LC 滤波] ──► +3.3VA (模拟轨) ──► AG32 VDDA33 (PIN_6)
`

### 5.1 接地与抗干扰设计准则
1. **星形单点共地**：功率地（PGND，DRV8316 功率管回路）与数字/模拟地（AGND/DGND）在电源输入电容的地焊盘处单点汇流，切忌大电流回流穿过 AG32 和 MT6701 下方。
2. **中心散热焊盘（EPAD）**：AG32 和 DRV8316 底部的大焊盘必须开窗，并在焊盘上打至少 9 个 0.3mm 散热过孔直通背面大面积地铜箔，保证高频散热与最低寄生电感。
3. **时钟走线保护**：
   - 8MHz 外部晶振走线长度 $\le 10	ext{mm}$，外围完整包地屏蔽；
   - MT6701 SSI 时钟（PIN_13）与 SPI 时钟（PIN_18）严禁与相电流敏感模拟线（PIN_10~12）平行走线。

## 6. 生产与烧录验收指引

板卡完成贴片焊接后，通过 DAPLink 烧录验证时序如下：

1. **第 1 步：烧录 CPLD 硬件位流（确定引脚路由）**
   `ash
   C:/Users/Administrator/.platformio/penv/Scripts/pio.exe run -e foc2205 -t logic
   `
2. **第 2 步：烧录 MCU 应用程序固件**
   `ash
   C:/Users/Administrator/.platformio/penv/Scripts/pio.exe run -e foc2205 -t upload
   `
3. **第 3 步：控制台自检日志核对**
   连接 PIN_20 (TX) 和 PIN_21 (RX) 到串口助手（115200bps）：
   - BootMode=0：确认 BOOT1/BOOT0 纯净锁存 Flash 启动模式；
   - [DRV8316] Unlock & 3x PWM Mode Config OK：确认 PIN_28 使能时序正常；
   - [MT6701] Angle Read: 24-bit frame OK, CRC Verified：确认 12.5MHz 编码器读取无差错。
