# FOC2205 QFN32 芯片引脚评估与分配规范

**芯片型号**：AGM 遨格芯 AG32VF303KCU6  
**芯片封装**：QFN32（32 物理管脚 + 底部外露接地焊盘 EPAD）  
**内核架构**：RV32IMAFC (200MHz) + 片上集成 2K LE CPLD 逻辑阵列  
**设计目标**：针对三相无刷电机 FOC 闭环系统（DRV8316 驱动 + MT6701 磁编码器），穷尽评估引脚物理容量与外设分配合法性，**杜绝占用 JTAG 5 线调试口与 HSE 外部晶振引脚**。  
**文档归属**：FOC2205/docs/FOC2205_QFN32芯片引脚评估与分配规范.md  
**生效版本**：V2.0（引脚冲突清零与时序收敛正式版）

## 一、 QFN32 物理引脚资源宏观统计与容量证明

AG32 芯片采用异构架构，其物理 Pin 脚（Die Pad）通过内部可编程互连阵列连接到片上 MCU 外设与 CPLD 逻辑单元。

### 1.1 芯片 32 个物理管脚刚性分类

依据官方规范（docs/AGM_DAP_LINK_Rev2.51.pdf 第 12-13 页 QFN32 引脚表及片上宏单元物理绑定）：

| 管脚大类 | 包含引脚编号 | 数量 | 占用性质与约束说明 |
|:---|:---|:---:|:---|
| **固定电源与地 (Power/GND)** | PIN_6 (VDDA33), PIN_16 (VDD33), PIN_32 (VDD33), PIN_17 (GND) | **4** | **物理不可挪用**。供电与模拟去耦。 |
| **系统控制专线 (System Control)** | PIN_4 (NRST 硬件复位), PIN_30 (BOOT0 启动模式) | **2** | **物理不可挪用**。NRST 接按键/RC，BOOT0 默认下拉接地。 |
| **外部 HSE 高频晶振 (Oscillator)** | PIN_2 (OSC_IN), PIN_3 (OSC_OUT) | **2** | **本设计严格保留**。保留给 8MHz~25MHz 外部晶体，禁止配置为通用 IO。 |
| **标准 5 线 JTAG 调试接口 (JTAG)** | PIN_24 (JTMS), PIN_25 (JTCK), PIN_26 (JTDI), PIN_27 (JTDO), PIN_28 (JNTRST) | **5** | **本设计严格保留**。保留给 DAPLink / JTAG 仿真烧录与片上 CPLD 调试，禁止挪用。 |
| **用户可自由分配 IO (User IOs)** | PIN_1, PIN_5, PIN_7~PIN_15, PIN_18~PIN_23, PIN_29, PIN_31 | **19** | **全部可供项目外设配置使用的物理 IO 资源**。 |
| **总计** | **PIN_1 ~ PIN_32** | **32** | - |

### 1.2 项目外设功能引脚需求数学清算

针对 DRV8316CRRGFR 三相栅极驱动器 + MT6701QT-STD 绝对值磁编码器的全功能 FOC 闭环系统，所需信号线精算如下：

| 功能子系统 | 信号定义 | 信号数量 | 硬件功能与接口属性 |
|:---|:---|:---:|:---|
| **三相逆变器 PWM** | PWM_A (INHA), PWM_B (INHB), PWM_C (INHC) | **3** | 高级定时器 GPTIMER0_CH0~CH2 互补驱动，3x 模式上桥控制 |
| **三相电流采集** | SOA (Phase A), SOB (Phase B), SOC (Phase C) | **3** | 芯片专用模拟通道 ADC_IN3, ADC_IN4, ADC_IN5 |
| **MT6701 磁编码器** | SSI_CLK, SSI_CSN, SSI_DO (MISO) | **3** | 12.5MHz 硬件 SSI 协议（CPLD SPI1 桥接 + 硬件 CSN 定时） |
| **DRV8316 寄存器配置** | SCLK, SDI (MOSI), SDO (MISO), nSCS (CSN) | **4** | 6.25MHz 专用 SPI 通信（CPLD SPI0 桥接，配置工作模式与故障保护） |
| **DRV8316 控制与使能** | nSLEEP, INL_ALL (INLA/B/C 并联) | **2** | GPIO2_1 唤醒使能，GPIO2_2 下桥常开硬件互锁信号 |
| **硬件故障极速保护** | nFAULT (故障开漏信号输入) | **1** | 高级定时器 GPTIMER0_BRK 硬件刹车输入（低电平直接封锁 PWM） |
| **调试与交互串口** | UART0_TX, UART0_RX | **2** | 控制台命令交互与力矩/位置遥测数据流（115200bps） |
| **需求引脚总计** | - | **18** | **实际所需引脚总数** |

### 1.3 引脚容量评估结论
\text{剩余可用 IO 数量} = \text{可用用户 IO (19)} - \text{功能需求 IO (18)} = \mathbf{1 \text{ 个 (PIN\_1 为 Spare 空闲备用)}}

**评估结论**：
1. **引脚数量完全充足**：在完全不牺牲 5 线 JTAG 调试口、不牺牲外部晶振输入、支持完整三相电流采样与全部硬件保护机制的前提下，AG32 QFN32 芯片完全能够胜任 FOC2205 项目。
2. **仍具备扩展冗余**：物理引脚 PIN_1 处于完全空闲状态，后续可作为用户按键、状态指示灯（LED）或上位机同步触发信号。

## 二、 关键引脚冲突排查与重映射记录

在早期设计方案中，曾存在两处严重的引脚冲突隐患，本次已彻底排查并完成硬件引脚重构：

### 2.1 冲突项 1：GPTIMER0_BRK 挤占 PIN_26 (JTDI)
- **历史分配**：DRV8316 的故障告警输出信号 
FAULT 接入了 PIN_26。
- **冲突危害**：PIN_26 是芯片原生的 **JTAG 数据输入脚（JTDI）**。一旦复用为刹车输入，标准 5 线 JTAG 仿真器（如 J-Link 或特定边界扫描工具）将彻底失效；同时在烧录过程中若 nFAULT 为低电平，可能干扰 JTAG 扫描链。
- **重映射方案**：将 GPTIMER0_BRK 移出，改接至 **PIN_22（IO_USBDM）**。
- **方案安全性评估**：PIN_22 是 AG32 内部 USB 控制器的 DM 差分引脚裸片焊盘，但在本项目未启用 USB 外设时，它作为标准的高速数字 IO 挂接在片上 IO 矩阵中，具备内部上拉与施密特触发输入，完美满足纳秒级刹车信号响应。

### 2.2 冲突项 2：spi1_miso_i 挤占 PIN_28 (JNTRST)
- **历史分配**：MT6701 磁编码器的 SSI 数据输出信号 DO 接入了 PIN_28。
- **冲突危害**：PIN_28 是芯片原生的 **JTAG 测试复位脚（JNTRST）**。复用此引脚会导致仿真调试器每次尝试 TAP 复位时破坏编码器通信，甚至在调试器插入时直接将编码器总线强行拉低导致读角失败。
- **重映射方案**：将 spi1_miso_i 移出，改接至 **PIN_23（IO_USBDP）**。
- **方案安全性评估**：PIN_23 为 USB 模块的 DP 差分引脚裸片焊盘，在禁用 USB 时具备标准数字输入特性，实测 12.5MHz 时钟下建立时间（Setup Time）满足 SSI 数据接收要求。

## 四、 硬件电气与时序特性匹配深度审查

除了引脚数量匹配外，引脚所挂载的片上逻辑与电气拓扑需完全满足芯片外设规范：

### 4.1 模拟引脚通道专用性（ADC 采样路径）
- **选型核验**：相电流检测采用了 PIN_10、PIN_11、PIN_12，对应芯片内部固定的专用模拟通道 ADC_IN3、ADC_IN4、ADC_IN5。
- **抗干扰设计要求**：PCB 走线时，DRV8316 的 SOA/SOB/SOC 输出端到 AG32 该 3 个引脚的走线必须做地线包裹屏蔽，且距离必须最短，各通道并联 100pF NPO/C0G 滤波电容，防止 PWM 开关毛刺耦合进入 ADC。

### 4.2 CPLD 硬件 SPI 模式转换桥（解决 Mode 0 硬件锁死缺陷）
- **缺陷背景**：AG32 原生硬核 SPI0/SPI1 控制器硬件固定为 **SPI Mode 0**（CPOL=0, CPHA=0）。但 DRV8316 与 MT6701 均强制要求 **SPI Mode 1**（CPOL=0, CPHA=1，在时钟上升沿移出数据、下降沿采样数据）。
- **逻辑桥实现**：引脚 PIN_18, 19, 29, 31 与 PIN_13, 14, 23 并非直连 MCU 硬核，而是穿过片上 2K LE CPLD 构造的 spi_mode_wrap.v 模块。CPLD 自动将时钟前导边沿进行反相与相位对齐，在硬件物理层解决了协议不兼容问题。

### 4.3 硬件刹车极速切断链路（BRK）
- **响应时间论证**：PIN_22 映射到 GPTIMER0_BRK。当 DRV8316 检测到过流、过温或欠压故障时，其 
FAULT 开漏引脚拉低。
- **纳秒级保护**：信号进入 PIN_22 后，不经过任何软件中断，直接由定时器硬件逻辑在 **1 个系统时钟周期（5ns）** 内将 PWM 输出强行封锁为高阻态或低电平，彻底杜绝 MOS 击穿风险。

## 五、 结论与硬件 PCB 画板实施指南

1. **项目引脚规划已正式定型**：FOC2205/foc2205.ve 配置文件已严格依据本规范更新，CPLD 布局布线时序完全收敛。
2. **PCB 工程师接线准则**：
   - 保证 PIN_24 ~ PIN_28 走线直接引出至 1.27mm / 2.54mm 排针或测试点，提供完整的 JTAG / DAPLink 接口。
   - PIN_2 与 PIN_3 靠近芯片放置 8MHz 晶振及 22pF 匹配电容，走线做包地处理。
   - PIN_1 标注为 TEST_IO / SPARE，可就近引出至测试焊盘。
   - PIN_22（nFAULT）走线上需预留 4.7kΩ~10kΩ 上拉电阻至 3.3V。
