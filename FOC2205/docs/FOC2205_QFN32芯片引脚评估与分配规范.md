# FOC2205 QFN32 芯片引脚评估与分配规范

**芯片型号**：AGM 遨格芯 AG32VF303KCU6  
**芯片封装**：QFN32（32 物理管脚 + 底部外露接地焊盘 EPAD）  
**内核架构**：RV32IMAFC (200MHz) + 片上集成 2K LE CPLD 逻辑阵列  
**设计目标**：针对三相无刷电机 FOC 闭环系统（DRV8316 驱动 + MT6701 磁编码器），穷尽评估引脚物理容量与外设分配合法性，**严格做到：零占用 JTAG 5 线调试口、零占用 HSE 外部晶振引脚、零占用 BOOT1 系统启动引脚**。  
**文档归属**：FOC2205/docs/FOC2205_QFN32芯片引脚评估与分配规范.md  
**生效版本**：V3.1（INL_EN=PIN_28/JNTRST 复用；BOOT1 独立、晶振与调试口 PIN_24~27 零占用）

## 一、 QFN32 物理引脚资源宏观统计与容量证明

AG32 芯片采用异构架构，其物理 Pin 脚（Die Pad）通过内部可编程互连阵列连接到片上 MCU 外设与 CPLD 逻辑单元。

### 1.1 芯片 32 个物理管脚刚性分类

依据官方规范（docs/AGM_DAP_LINK_Rev2.51.pdf 第 12-13 页 QFN32 引脚表及片上宏单元物理绑定）：

| 管脚大类 | 包含引脚编号 | 数量 | 占用性质与约束说明 |
|:---|:---|:---:|:---|
| **固定电源与地 (Power/GND)** | PIN_6 (VDDA33), PIN_16 (VDD33), PIN_32 (VDD33), PIN_17 (GND) | **4** | **物理不可挪用**。芯片供电与模拟去耦。 |
| **系统控制专线 (System Control)** | PIN_4 (NRST 硬件复位), PIN_30 (BOOT0 启动模式), **PIN_15 (BOOT1 启动模式)** | **3** | **严格保留独立，0 占用**。NRST 接按键/RC，BOOT0/BOOT1 均 10k 下拉接地，纯净保障从 Flash 启动。 |
| **外部 HSE 高频晶振 (Oscillator)** | PIN_2 (OSC_IN), PIN_3 (OSC_OUT) | **2** | **严格保留独立，0 占用**。保留给 8MHz~25MHz 外部晶体，禁止配置为通用 IO。 |
| **JTAG 调试接口 (DAPLink)** | PIN_24 (JTMS), PIN_25 (JTCK), PIN_26 (JTDI), PIN_27 (JTDO) | **4** | **严格保留独立，0 占用**。DAPLink 仅走 2 线 Compact-JTAG（TCK/TMS），此 4 脚足够完成烧录与片上 CPLD/MCU 调试。 |
| **JNTRST 业务复用** | PIN_28 (JNTRST) | **1** | nTRST 为可选信号（TAP 复位可用 TMS 高电平 5 拍替代，2 线 DAPLink 从不驱动它），故允许作为用户 IO 分配（本板 = INL_EN）。 |
| **用户可自由分配纯净 IO (User IOs)** | PIN_1, PIN_5, PIN_7~PIN_14, PIN_18~PIN_23, PIN_28, PIN_29, PIN_31 | **19** | **可供项目外设配置使用的全部独立物理 IO 资源**（本板用 18，余 PIN_1 备用）。 |
| **总计** | **PIN_1 ~ PIN_32** | **32** | - |

### 1.2 项目外设功能引脚需求数学清算

针对 DRV8316CRRGFR 三相栅极驱动器 + MT6701QT-STD 绝对值磁编码器的全功能 FOC 闭环系统，所需信号线精算如下：

| 功能子系统 | 信号定义 | 信号数量 | 硬件功能与接口属性 | 分配引脚 |
|:---|:---|:---:|:---|:---:|
| **三相逆变器 PWM** | PWM_A (INHA), PWM_B (INHB), PWM_C (INHC) | **3** | 高级定时器 GPTIMER0_CH0~CH2 互补驱动，3x 模式上桥控制 | PIN_7, PIN_8, PIN_9 |
| **三相电流采集** | SOA (Phase A), SOB (Phase B), SOC (Phase C) | **3** | 芯片专用模拟通道 ADC_IN3, ADC_IN4, ADC_IN5 | PIN_10, PIN_11, PIN_12 |
| **MT6701 磁编码器** | SSI_CLK, SSI_CSN, SSI_DO (MISO) | **3** | 12.5MHz 硬件 SSI 协议（CPLD SPI1 桥接 + 硬件 CSN 定时） | PIN_13, PIN_14, PIN_23 |
| **DRV8316 寄存器配置** | SCLK, SDI (MOSI), SDO (MISO), nSCS (CSN) | **4** | 6.25MHz 专用 SPI 通信（CPLD SPI0 桥接，配置工作模式与故障保护） | PIN_18, PIN_19, PIN_29, PIN_31 |
| **DRV8316 控制与使能** | nSLEEP, INL_ALL (INLA/B/C 并联) | **2** | GPIO2_1 唤醒使能，GPIO2_2 下桥常开硬件互锁信号 | PIN_5, **PIN_28** |
| **硬件故障极速保护** | nFAULT (故障开漏信号输入) | **1** | 高级定时器 GPTIMER0_BRK 硬件刹车输入（低电平直接封锁 PWM） | PIN_22 |
| **调试与交互串口** | UART0_TX, UART0_RX | **2** | 控制台命令交互与力矩/位置遥测数据流（115200bps） | PIN_20, PIN_21 |
| **需求引脚总计** | - | **18** | **实际所需引脚总数** | **18 个全部落定** |

### 1.3 引脚容量评估结论
\text{可用纯净 IO (19)} - \text{实际需求 IO (18)} = \mathbf{1 \text{ 备用（PIN_1），零冲突}}

**评估结论**：
1. **绝对零冲突**：在不占用 DAPLink 调试口（PIN_24~PIN_27；nTRST 属可选信号已让位业务）、不占用外部晶振、不占用 BOOT 启动引脚的前提下，AG32 QFN32 芯片满足全功能 FOC 驱动系统的 18 个外设信号需求，另余 PIN_1 备用。
2. **BOOT1 专职专用**：PIN_15 (BOOT1) 彻底解放，纯净用于 10k 下拉接地，与 PIN_30 (BOOT0) 共同构成硬件级 {BOOT1, BOOT0} = 00b 锁存网络，杜绝任何运行期 IO 翻转对启动逻辑的潜在隐患。

## 四、 硬件 PCB 走线设计指导原则

1. **BOOT 专线布线**：
   - PIN_15 (BOOT1) 与 PIN_30 (BOOT0) 附近分别放置 10kΩ 电阻下拉到 GND，走线尽量短直，远离任何 PWM 高频斩波网络，确保上电瞬态不受电磁干扰误触发。
2. **下桥使能 PIN_28**：
   - PIN_28 (JNTRST) 连接到 DRV8316 的 INLA/B/C 并联网络，走线上保留 10kΩ 下拉电阻（确保上电与模式切换期间下桥处于可靠关断状态；复位期 JNTRST 片内上拉被该强下拉支配）。
3. **JTAG 调试插针**：
   - PIN_24 ~ PIN_27 走线直接引出至 1.27mm / 2.54mm 排针或测试点（PIN_28 已作 INL_EN 复用；DAPLink 2 线模式仅需 TCK/TMS，不受影响）。
4. **外部晶振**：
   - PIN_2 与 PIN_3 靠近芯片放置 8MHz 晶振及 22pF 匹配电容，走线做包地处理。
