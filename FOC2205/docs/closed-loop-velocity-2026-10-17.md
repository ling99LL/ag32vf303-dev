# FOC2205 闭环速度控制与平滑验收（fw=20261017.24）

2026-10-17，COM26 115200 8N1。目标：解决闭环 SPIN 在低速和整圈旋转时的卡顿、抖动、饱和翻转与高力度过流，使闭环手感达到开环同级。

## 结论

1. **闭环 20% V1–V4 正反向 8/8 PASS**：实测 2.93/2.99/5.96/5.92/15.06/14.89/59.20/59.31 rpm，巡航 `cv=4.56–13.32%`，零失速、零反向步进、零连续过流。
2. **高力度闭环 40%/80% 8/8 PASS**：V2 与 V4 正反向 `cv=3.25–10.09%`，无 `n=3` 过流、无编码器故障。
3. **开环同级对照 8/8 PASS**：同条件 20% 开环 `cv=3.29–14.08%`。闭环与开环已处于同一水平，低速 V1 闭环还略优。
4. **上位机实连通过**：隐藏 Tk 窗口连接 COM26，闭环 V2/20% 实测均值 5.77 rpm（目标 6.00 rpm），ISR 20,008 Hz；停止后 `out=0`。`rot +360/-360` 两个位置按钮也均完成并安全释放。
5. **失联保护保持通过**：SPIN 运行中 3.5 s 无宿主命令，自动回到 `mode=0,st=0,out=0`。
6. **可选电流环冒烟通过**：`l` 打开后，V2/20% 实测约 5.95 rpm、`cv≈13.6%`；V4/20% 实测约 59.36 rpm、`cv≈7.1%`。释放后恢复 `cur_ref_div=12`，默认电压模式不变。

## 根因

旧闭环 SPIN 实际是“无限位置斜坡 + 位置误差直接输出电压”。在 2205 小电机和静摩擦区间内，位置误差一旦超过阈值就把 `vq` 打到 `±1638`，随后反冲，形成饱和极限环。10-17 20:18 的旧日志中，V2/20% 闭环在 100 ms 级采样里出现 `vq=+1638 → -1638` 和角度正反大幅跳变，`cv=121.52%`。

同时，直接使用编码器电角度做低速换向会遇到 Coulomb 摩擦的“粘住/突然跳走”区间：

- 固定 `vq=150` 或 `200` 时转子不动；
- 固定 `vq=300` 时转子约 1.7 rps；
- 单纯速度 PI 在 0.05–0.10 rps 附近容易在 0 与 1 rps 两个状态间切换。

## 采用的 SimpleFOC 方案

参考 SimpleFOC 的速度控制结构：

- [Arduino-FOC](https://github.com/simplefoc/Arduino-FOC)
- `FOCMotor::move()` 中 `PID_velocity(shaft_velocity_sp - shaft_velocity)` 的速度 PI；
- `PIDController` 的积分限幅、输出限幅和 `output_ramp`；
- `LPF_velocity` 测速低通与 `velocity_control` 示例；
- [SimpleFOC velocity loop 文档](https://docs.simplefoc.com/velocity_loop)。

本项目没有直接照搬 Arduino 电压单位，而是适配为 Q12 调制域，并增加同步换向前馈：

1. 编码器机械速度每 256 拍更新一次，再经 15 ms 低通；
2. 速度 PI 直接输出 `torque_q`，默认 `vp=0.010`、`vi=0.050`；
3. 电气角按目标机械速度同步前馈，启动时从当前电角度后 90° 起步；
4. 电压基线固定为已验证的 20% 调制（`1638/8192`），PI 只做误差补偿，向上开放到用户力度上限；
5. 输出斜率限制、积分条件抗饱和；停止时先降到零电压，再等速度低于 0.01 rps 后释放；
6. 位置动作和 m0–m4 手感仍走原路径，不与 SPIN 速度环共享增益。
7. 电流环开启时，SPIN 临时把 Q12 力矩命令按 1:1 映射为电流参考（`cur_ref_div=1`），释放后恢复原值；否则默认 `/12` 映射只有约 136 LSB，无法提供足够低速推力。

新增命令：

```text
vp <q12 per raw/s>     速度环 P，默认 0.010
vi <q12 per raw/s^2>   速度环 I，默认 0.050
vff <q12 per raw/s>    可选速度前馈，默认 0
vfr <q12>              可选摩擦补偿，默认 0
```

状态帧新增 `vsp/vfb/verr/vkp/vki/vff/vfr`，上位机可显示目标速度、实测速度、误差和当前速度环参数。

## 上位机验证

- `gui_spin_smoke.py`：连接 COM26，选择闭环 V2/20%，目标 6.00 rpm，最终镜像实测均值 5.77 rpm，ISR 20,008 Hz；停止后 `out=0`。
- `gui_position_smoke.py`：通过面板路径发送 `rot +360` 和 `rot -360`，两个动作均收到 `MOVE DONE`，最终 `st=0/out=0`。
- `foc_protocol.py` 修正 `cl/open` 被当成字符串导致 `bool('0') == True` 的闭环误判；SPIN 命令全部换行化，并在连续参数/启动命令间加 20 ms 节流，避免 UART FIFO 丢换行。

## 烧录恢复

本轮 `.24` 烧录后再次遇到已知的首次 CPLD 访问卡死（`dmstatus=0x00030ca2`）。`CONNECT_UNDER_RESET` 重写 CPLD 后，使用 WDOG 复位序列成功恢复 COM26：

```tcl
mww 0x40012800 0x1ACCE551
mww 0x40011c00 0x10
mww 0x40011c08 0x2
resume
```

恢复后重新校准 `calst=7`、`calpk=419`，再进行上述矩阵。该路径仍是恢复 workaround，不代表首次 CPLD 访问卡死已根因修复。

## 边界

- 力度仍是 Q12 调制/电流请求上限，不是仪器标定的物理力矩；没有相电流或母线波形。
- 自动证据证明速度、状态机、保护和 GUI 路径；m1 黏滞、m2 飞轮、m3 咔哒、m4 边界的人工体感仍需实际操作确认。
