# FOC2205 元件引脚连接网表（信号互联）

**范围**：元件与元件之间的信号互连 + 信号网络上的必需电阻/电容。**电源树、去耦电容、地平面不在本文档**，见《DRV8316+MT6701_FOC驱动板接线设计》§5。
**依据**：`foc2205.ve`（v6.1）+ 接线设计 v6.1 + 引脚规范 V3.1 + 两份规格书逐脚核对（TI SLVSH07 p.4-5 表 6-1；麦歌恩 MT6701 1.9 版 p.3-4）。
**版本**：v1.0（2026-10-03）

|:---|:---|:---:|:---|

## 6. 片内路径备注（理解引脚复用的键）

- AG32 硬 SPI 固定 mode 0，因此两路 SPI 在 **CPLD 内经 `spi_mode_wrap.v` 转为 mode 1** 再出 pad：MCU 侧 SPI0/SPI1 = 帧发生器，`DRV_SCK/DRV_MOSI/DRV_CSN`、`MT_CLK` 由桥整形输出，`DRV_MISO`/`MT_DO` 由桥在采样沿捕获进 `SPIW_RXDATA0/1`（APB 0x60007000），固件直读。
- GPIO 位分配：`GPIO2_0`→PIN_14（MT_CSN，经逻辑透传）、`GPIO2_1`→PIN_5（DRV_SLP，直连）、`GPIO2_2`→PIN_28（INL_ALL，直连）。GPIO0_0/0_1 与 SPI0_SI/SO 同物理位，禁用。
