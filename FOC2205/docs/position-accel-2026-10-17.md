# 位置轨迹加减速修复与 0.25/0.50 档复测（fw=20261017.12）

日期：2026-10-17。端口：COM26，115200 8N1。测试脚本：`experiments/tests/current_loop/smoothness_sweep.py` 的 `edges12` 与 `fast` 块。

## 根因

有限位置动作 `motion_start_turns()` 原来在第一个 ISR 周期就直接把轨迹步进设为目标巡航速度：

- 0.50 圈/秒起步时，位置指令瞬间跳变，位置环立即给出较大的 q 轴调制，容易触发 MT6701 场状态中止或真实连续超阈跳闸。
- 0.25 圈/秒结束时，轨迹又从巡航速度突然停住，末端冲击与间歇性 `current ADC threshold n=3` 的时序一致。
- SPIN 早已有 0.75 圈/秒² 的斜坡；有限位置动作没有复用这套斜坡。

## 修复

`src/motion.c` 增加 `MOTION_POS_ACCEL_RPS2 = 0.75f`，并为位置模式增加梯形轨迹：

- 起步从 0 逐步加速到目标圈/秒。
- 按剩余距离和当前步进计算减速点，接近目标时逐步降速。
- 最后一步使用精确剩余距离，避免因整数 Q16 取整停在目标外。
- 速度为 0 但误差仍小于 `err_limit` 时允许重新起步，防止轨迹停在目标前。
- 主机回归中的 200 圈测试改用 0.2 圈/秒，使模拟转子的理想速度与新斜坡保持在同一误差窗口内。

## 实机结果

默认 `hyb=0`。0.25/1536 与 0.50/1013、0.50/768 的 10 次矩阵使用 `kp=8`、`kd=60/1000`、`ang_filt=1/256`、电流环 ON；0.50 的 1013/1536/2048 补充行使用 `fast` 块的 `kp=2` 配置。

| 条件 | 通过数 | 结果 | 时长/次 | cv | 残差 |
|---|---:|---|---:|---:|---:|
| 0.25 圈/秒，1536 力度 | 10/10 | 全 DONE，零 n=3，零 encoder 中止 | 4.378 s | 3.15–5.78% | +37 / -39 raw |
| 0.50 圈/秒，1013 力度 | 10/10 | 全 DONE，零 n=3，零 encoder 中止 | 2.713 s | 12.93–15.69% | +37 / -46 raw |
| 0.50 圈/秒，768 力度 | 10/10 | 全 DONE，零 n=3，零 encoder 中止 | 2.713 s | 11.33–16.43% | +31 / -38 raw |
| 0.50 圈/秒，1013 力度（补充，kp=2） | 2/2 | DONE | 2.713 s | 14.0 / 19.85% | +177 / -150 raw |
| 0.50 圈/秒，1536 力度（补充，kp=2） | 2/2 | DONE | 3.365–3.366 s | 51.13 / 56.63% | +194 / -187 raw |
| 0.50 圈/秒，2048 力度（补充，kp=2） | 2/2 | DONE | 3.586–3.634 s | 61.72 / 62.33% | +196 / -191 raw |

本轮目标矩阵共 36/36 次 DONE，所有结束状态均为 `st=0 out=0 brk=0`，无 `current ADC threshold n=3`，无 `encoder invalid/field`。

## 判读与边界

- 0.50 档“起步失败”已消除：1536/2048 高力度也能起步并完成，不再要求先退到低力度。
- 0.50 档高力度仍不平滑：1536/2048 的巡航 cv 约 51–62%，明显高于 1013/768；因此 0.50 档推荐仍以 1013 为主，1536/2048 只作为力度余量。
- 加减速使 0.50 单圈从约 2.1 s 增加到约 2.7–3.6 s，这是换取无起步跳闸和末端稳定性的代价。
- 证据仍来自编码器、ADC 遥测和故障帧；没有示波器相电流/母线波形，也没有带负载、温升和长期 soak 结论。
