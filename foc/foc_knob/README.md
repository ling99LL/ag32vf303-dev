# AG32VF303KCU6 (QFN32) FOC 力反馈旋钮

用 AGM AG32VF303KCU6（RISC-V 200MHz + 2K LE CPLD）+ 三相输入跟随驱动板 + 电机内置霍尔，
实现 SimpleFOC 风格的力反馈旋钮（棘轮档位 / 阻尼 / 惯性 / 有界 / 弹簧 / 自由）。

参考项目（侧边浏览器打开的两篇）：

- CSDN《基于FOC的项目----力反馈旋钮》：https://blog.csdn.net/2401_88493720/article/details/148234504
- GitHub qihemu/FOC_Knob（loop222 的 SimpleFOC STM32 移植二次开发）：https://github.com/qihemu/FOC_Knob

与参考项目的差异：参考驱动板带电流采样（电流环力矩），本驱动板只有
IN1/IN2/IN3/EN/RESET/SLEEP/FAULT（**无电流采样**），因此采用 SimpleFOC 标准的
**电压模式力矩控制**（Uq 电压 ∝ 力矩），全部旋钮效果同样适用。编码器为电机
内置霍尔（5 线：VCC/GND + HU/HV/HW），用 60° 电角度扇区 + 边沿时间插值求角度
（SimpleFOC HallSensor 方法），**无需精确编码器找零**。

## 引脚分配（foc_knob.ve）

| QFN32 pad | .ve 功能 | 接驱动板/电机 | 说明 |
|---|---|---|---|
| 7 | GPTIMER0_CH0 | IN1 | 三相 SVPWM，20kHz 中央对齐 |
| 8 | GPTIMER0_CH1 | IN2 | 同一定时器同步计数 |
| 9 | GPTIMER0_CH2 | IN3 | |
| 10 | GPIO0_0 | EN | 高电平使能，上电默认关 |
| 11 | GPIO0_1 | RESET | 低有效，平时高，可软复位驱动芯片 |
| 12 | GPIO0_2 | SLEEP | 低有效，平时高；拉低 = 旋钮"休眠" |
| 13 | GPIO0_3 | FAULT | 输入低有效，过流/过温实时封 PWM |
| 26 | GPIO0_4 | HALL_U | 霍尔三根同在 GPIO0 端口 → 一个中断处理 |
| 29 | GPIO0_5 | HALL_V | pad 27=JTDO（调试 TAP 占用，GPIO 输入无效），换到纯 IO 的 29 |
| 28 | GPIO0_6 | HALL_W | |
| 20 | UART0_TX | DAPLink RX | 调试串口 115200（手册推荐保留口） |
| 21 | UART0_RX | DAPLink TX | |
| 5 / 14 | （未分配） | — | 固定 ADC_IN12 / ADC_IN7，留作将来电流采样 |
| 18 / 19 / 29 / 31 | （未分配） | — | 留作 SPI/I2C 磁编码器升级等 |

分配原则：三相 PWM 相邻（7/8/9）方便走线到驱动板 JST 座；驱动板控制信号
顺次（10-13）；霍尔三根连续（26/29/28）且与 FAULT 同用 GPIO0 端口——一个
`GPIO0_isr` 搞定全部边沿中断；调试串口用手册指定的 PIN_20/21（不在你的可分配
清单内，正好保留）。

## 硬件注意事项（上电前必读）

1. **霍尔上拉（强烈建议，实测必须）**：霍尔线若不上拉，PWM 相线电流的开关噪声
   会耦合进霍尔线（实测：静止时干净，uq 一加力矩就出现 1~2ms 间隔的假边沿，比真实
   信号多两个数量级，闭环直接乱套）。**每根霍尔线对 3.3V 加 4.7~10kΩ 上拉**，
   霍尔线远离相线、与 GND 绞合，电机/驱动板/MCU 共地。固件已有 80µs 去抖 +
   800 扇区/s 限速滤波 + 堵转保护，但噪声过大时硬件才是根治手段。
2. **QFN32 的 JTAG 引脚坑（实测）**：AG32VFxxxK 的 pad 24~28 = JTMS/JTCK/JTDI/
   JTDO/JNTRST。**pad 27（JTDO）被调试 TAP 占用，GPIO/CPLD 输入收不到任何信号**
   （.ve 映射合法、位流正确也没用）；pad 26（JTDI）/28（JNTRST）实测可作输入。
   信号线优先用纯 IO pad（18/19/29/31）。SDK 有 `SYS_DisableJTDO()`（SWJ_CNTL
   寄存器）可释放 JTAG 脚，见 system.h，未在本项目采用（直接换了 pad 29）。
2. **霍尔供电电平**：若电机霍尔需要 5V 供电，其输出高电平约 4.5V，超过 AG32
   3.3V IO 耐压——先确认霍尔支持 3.3V 供电（很多电机霍尔 4.5~5.5V 供电、
   输出 VOH≈VCC-0.5V，3.3V 供电下能工作但幅度偏低），必要时加电平转换或串 10k。
3. **供电**：驱动板 3.3V 输出最大仅 10mA，**不要**用它给 AG32 板供电
   （只够给霍尔之类的小负载）。12V 母线用稳压电源；固件按 `VBUS_VOLTAGE 12.0f`
   换算占空比，换电压要同步改这个宏。
4. **DAPLink 连接**（首次烧录）：QFN32 只接 TCK/TMS/GND/VCC3V3 四根
   （DAPLink JTAG 口 → 芯片 pad25 JTCK / pad24 JTMS），**J3V 跳线必须连通**
   给目标板供电；DPIDR=0x00000000 = 目标没电，先查 J3V。
5. 上电校准时电机会自动转动约 1.5 秒（对齐 + 扫角度），**旋钮保持自由空转**。
6. **FAULT 排障**：驱动板 FAULT 是开漏输出，若板上没上拉、或没接 pad13，
   固件可能一直读到"故障"并在校准后立刻锁存关断（状态里显示 FAULT）。
   给 pad13 加 10k 上拉到 3.3V；临时调试也可以先不接这根线（仅失去硬件
   过流保护）。

## 上电流程

1. 烧录后复位，串口打印横幅和命令表（波特率 115200）。
2. 电机上电后是**瘫软**的（输出关闭）。输入 `scan`（推荐）：
   - 开环拖动一整圈（~7s），把霍尔跳变的原始序列+时刻全部记录下来
   - 拖动计划本身就是电角度真值：相序、方向、锚点全部**实测**（不再猜 flip）
   - 转子锚点与引脚状态交叉校验，失败即报（错乱=噪声/被碰）
   - 成功后 FOC 闭环启动，`rot` 速度自动限到 50°/s（≤开环拖动节奏）
   - 备用：`cal`（旧法：对齐+180°电角度扫向，靠启发式判向，锚点有随机误差）
3. 手转旋钮，串口 `p` 看角度/速度/霍尔扇区是否连续合理。
4. `pp` 量极对数：提示后**手转正好一整圈**，打印估算值；不是 6.0 就
   `ppset <值>`（9 槽电机常见 9N12P=6，即默认值；极对数只影响机械角度标度
   和档位数量，不影响 FOC 本身）。
5. 试手感：`m3` 挡位（SmartKnob 引擎，默认 30°/档）→ `m1` 阻尼 → `m2` 惯性 →
   `m4` 有界 → `m5` 弹簧回中 → `m0` 自由。

## 串口命令

| 命令 | 作用 |
|---|---|
| `h` | 命令帮助 |
| `m0`..`m5` | 模式：0 自由 / 1 阻尼 / 2 惯性 / 3 挡位（SmartKnob 引擎）/ 4 有界 / 5 弹簧 |
| `p` / `s` / `st` | 状态一次 / 自动状态开关 / 完整状态（含 FOC 循环频率） |
| `cal` | 旧法霍尔校准（对齐 + 180°电角度扫向，电机会动；net 超出 ±4 判为霍尔噪声并失败） |
| `scan` | **首选校准**：开环拖一整圈并记录霍尔，实测相序/方向/锚点后直接闭环（~8s，电机全程自转，手别碰） |
| `pp` / `ppset <n>` | 测量 / 设置极对数（手转一圈实测 37 步 ≈ 36 → **6pp 确认**，默认即 6；scan 报 net≠36 时核对） |
| `ua <V>` | 校准对齐电压（默认 2.5V，拖不动转子时加大） |
| `fl 0/1` | 手动换相方向翻转（cal 判向可疑时 A/B 测试用） |
| `kp <f>` / `kd <f>` | 位置环 P（有界墙用）/ **弹簧/墙刹车幅值 kd**（定幅 bang 刹车，作用于"最后一颗真实钉方向"，静止自动归零；m3 挡位的 D 由宽度/力度自适应算出，m5 弹簧已改速率拖动、不用 kd） |
| `df <f>` / `fi <f>` / `kf <f>` | 阻尼 / 惯性 / 有界自由区增益（阻尼/惯性吃"边沿间隔真实速度"，轻碰边界不会乱炸；惯性助力上限 0.25V < 动摩擦，甩多快都不会自旋失控） |
| `vl <V>` | 力矩电压限幅（默认 3V，务必从小往大调） |
| `dw <deg>` | **m3 挡位宽度**（2~120°，默认 30°；引擎内部按霍尔扇区 10°@6pp 取整——挡位中心必须能对齐译码台阶，否则永远清不掉驻留力矩） |
| `ds <f>` / `es <f>` | m3 挡位力度 / 限位力度（P=力度×1.5 V/rad，D=0.05×力度。默认 5.0/4.0。设计目标：**偏 1~2 个霍尔扇区的持握力（0.9V/2.4V@ds5）低于 ~2.5V 静摩擦**——旋钮停在两挡之间也绝不自激抖动；偏 ≥3 扇区（真在两挡中间）才满幅 3V 吸附，咔哒感不受影响 |
| `sp <f>` / `sb <f>` | m3 吸附点（0.5~1.5×宽度，必须 ≥0.5 防相邻挡振荡）/ 吸附偏置（偏离 0 挡更难离开，"轻推回位"手感） |
| `pn <n>` / `px <n>` | m3 挡位序号下限 / 上限（默认 0/−1 = 不限圈数；`pn 0`+`px 0` = 单挡回中弹簧；`px≥pn` 时出界侧施加 es 力度） |
| `n <n>` | 每圈挡位数（兼容旧习惯，内部换算成 `dw = 360/n`） |
| `br <deg>` | 有界模式边界角（默认 ±45°） |
| `cd` / `z` | 把当前位置设为中心 / 角度清零 |
| `rot [deg]` | 旋转（默认 360°，负数反向；再发一次中止）。**非阻塞**：开环/闭环都由 20kHz 中断推进，主循环持续跑 → 旋转全程霍尔/角度在上位机实时可见。已校准 = **速率锁定拖动 + 位置微调**（磁场角按参考速率纯积分推进——与校准拖动同样顺滑，霍尔位置误差只以 ±10% 弯曲磁场速率；脱困时伺服到最大力矩角），带着陆减速坡、到位保持、落点误差实测 ±0°；未校准 = 开环拖动（完成后驱动器回到关闭） |
| `rs <deg/s>` | rot 旋转速度（默认 120，范围 10~720）。**scan 校准后上限强制锁为 50°/s**（≤ 开环拖动节奏 55.6°/s，手动调高会被钳回并提示 scan cap） |
| `sl 0/1` / `en 0/1` | 驱动板休眠 / 使能 |
| `cl` | 清除故障锁存（FAULT 触发后需手动清除） |
| `tel <hz>` | 机器遥测流 `$T,mode,ang(cdeg),vel(mrad/s),uq(mV),tgt(cdeg),hall,flags,loop_hz,pos,subpos(x100)`，供上位机绘图（0=关，50 常用；pos/subpos 为 m3 挡位引擎状态，其他模式为 0） |

**"点了没反应"四重防护**（新版 exe 内置，出问题时看这四样）：

- **未连接时点任何按钮** → 终端立刻红字
  `ERR 未连接，命令未发送: …（请先点"连接"）`，不再静默丢弃；

  "FocTuner 已在运行"后自动退出，串口不再被第二个实例抢走——这是
  "怎么点都没反应"的最常见原因（第二个窗口抢不到串口，所有点击被静默吞掉）；

  状态栏"⚠ 3 秒无遥测"，恢复后自动变绿（cal/pp 期间固件短暂阻塞属正常）；

## 调参指南

- **挡位 m3（SmartKnob 引擎移植）**：手感由五个参数决定——
  `dw` 挡位宽度（按霍尔扇区 10° 取整，10° 是物理上限）、`ds` 挡位力度
  （P = 力度×1.5 V/rad、D = 0.05×力度。**按霍尔量化重新标定**：偏 1~2 个扇区的
  持握力刻意低于 ~2.5V 静摩擦（0.75V/2.0V@ds5，含 D 也 <2.4V），停在两挡之间
  或松手带速度撞墙都必然"粘住"，绝不自激抖动；
  偏 ≥3 扇区（真的在两挡中间）才满幅 3V 吸附出"咔哒"。换挡计数几乎
  不限速（15 rad/s 以下都实时计），快甩不丢挡；跳不过去 → 加 `ds` 或 `vl`）、`es` 限位力度
  （`pn/px` 设界后越界侧的墙）、`sp` 吸附点（越大越"吸到底"才换挡，≥0.5 防振荡）、
  `sb` 吸附偏置（0 挡更难离开 = 轻推回位）。静止时死区 + 怠速回中保证零嗡鸣
  （|Uq| 应归零）；`|w|>30rad/s` 自动断力矩防飞车。引擎与 `rot` 兼容：
  旋转期间挡位计数照常推进。想复刻 SmartKnob 细档位（<10°）需要换磁编码器
  （板卡 18/19 pads 预留），霍尔 10° 台阶下 `ds` 需要 ≥2 才吸得动。
- **阻尼 m1**：`df` 越大转起来越"黏"。0.05 轻微、0.3 强阻尼。
- **惯性 m2**：`fi` 给正反馈模拟飞轮，**务必小**（0.03~0.08），过大一碰就飞转
  （程序里 `vl` 是最后防线）。
- **有界 m4**：`br 45` 圈内自由越界回弹；自由区想要一点油感 `kf 0.02`。
- **弹簧 m5**：先 `cd` 把当前位置设为中心，再调 `kp`。
  **2026-10-01 重做 = 速率锁定回中拖动**（不再是 P 弹簧）：偏离中心 >1 扇区时磁场角限速积分把转子"拖"回家（rot 同款架构，同步拖动不可能踢转子）；负载角护栏为 **cos 模型非对称钳**（施加矢量在 th_ff+90°，拉力=uq·cos(xw)：滞后侧钳 +0.15=2.96V 恒定破差拉力，超前侧钳 −2.2=刹车收调速——对称钳会在转子超前时仍保持 0.83 倍前向拉力，弹射 13rad/s）；**进度门+退避重试**（0.6s 无进展即松开，2/4/8s 后再礼貌试拉——局部静摩擦>3V 或用户按住时绝不持续 3V 驻立）；回到 0.6 扇区零力矩释放 → **静止=零力矩=绝对安静**。P 弹簧在本硬件上被全模式普查证伪：10° 量化台阶 + 译码相位误差会让任何 P 场里的运动自持振荡（D 越大越糟），转子真实只抖 ±1° 而译码画 30° 幻影摆。
- **速度交接法**（`host/drag_release_probe.py`）：m5 拖动把转子加速到 ≥0.8rad/s 后飞行中切目标模式——补齐 rot 落点法测不到的"带速度松手"场景（m0/m1/m2/m3×3 相位/m4 全 PASS）。
- **全模式防抖普查**（`host/all_mode_probe.py`，rot 驱动无手参与；`wall_hold_probe.py` 补墙驻留）：m0-m5 全部 20 项 + 墙驻留 6 项 PASS，连续两轮。m3 挡位间驻留的盒子弹跳由"反向率抖动检测 → 快速回中（τ0.5s）"在 ~1s 内吞掉。
- **循环频率**：`st` 看 loop=Hz。AG32 定时器中央对齐模式下更新中断可能在
  PWM 频率的 1 倍或 2 倍（20k 或 40k），固件用实测 dt，两种频率下控制数学都正确。

控制链路：`GPTIMER0 更新中断（20~40kHz，实测 dt）→ 霍尔插值角度/速度 →
旋钮模式算 Uq → 逆 Park → SVPWM → 三路 CCR`；霍尔边沿走 `GPIO0_isr` 只做
时间戳，不做重活。保护链：FAULT 拉低 → MOE 关断 + 锁存（`cl` 清除）；
霍尔非法态（000/111）→ 当拍零力矩。

## 已知限制 / 后续方向

- 无电流采样：力矩精度受电机相电阻和温度影响（旋钮手感场景完全够用）。
- 霍尔插值角度精度 ±30° 电角度（扇区中点假设）：力矩幅值最多损失 ~13%，
  不会反向；将来换 AS5600/MT6701 磁编码器（pad 18/19 等）可彻底消除。
- 参数不落盘：断电恢复默认值，改 `src/foc_knob.h` 宏或将来加 Flash 保存。
- pad 5/14 预留了固定 ADC 通道（ADC_IN12/IN7，经 CPLD analog_ip），
  将来驱动板若换带电流采样的版本，可升级真电流环。
